## 2. Role-Based Access Control (RBAC) Matrix
RBAC is strictly enforced across middleware, routes, and controllers:

| Role | Access Scope | Publishing Permissions | Key Privileges |
| :--- | :--- | :--- | :--- |
| **Management** | Full System | Direct Publish | User administration, RBAC role assignment, system settings, platform analytics. |
| **Editor** | Editorial Desk | Direct Publish | Review submission queue, approve/reject drafts with feedback, manage category beats. |
| **Journalist** | Writer Workbench | **Cannot self-publish** | Creates and edits own articles; must submit to editor for approval (`pending_review`). |
| **Contributor** | Writer Workbench | **Cannot self-publish** | Creates and edits own drafts; submits for editorial review (`pending_review`). |
| **Reader (Logged In)**| Public Platform | Read Only | Like articles, post discussion comments, save/bookmark to personal profile. |
| **Reader (Guest)** | Public Platform | Read Only | Like articles (IP-tracked). Commenting and bookmarking prompt a login modal. |

### 1. Akar Masalah
- **Pemisahan Ruang Lingkup (Scope Shadowing di Alpine.js)**: 
  Sebelumnya, elemen `<header>` mendeklarasikan `sidebarOpen: false` di dalam `x-data`-nya sendiri. Ketika tombol pemicu di dalam header diklik (`@click="sidebarOpen = true"`), Alpine.js hanya mengubah variabel lokal di lingkup `<header>`. 
  Sementara itu, komponen sidebar berada di luar header pada tingkat root `<body>`. Akibatnya, status buka/tutup pada sidebar tidak pernah menerima perubahan tersebut (*isolated scope*), sehingga sidebar tidak mau terbuka saat diklik.
